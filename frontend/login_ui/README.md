# login_ui

로그인 + 마이페이지 화면. `frontend/login_ui/`에 둔다.

- `My Page.dc.html`: 로그인(Google / 아이디·비밀번호) + 마이페이지. 브라우저에서 바로 연다.
- `support.js`: 화면 런타임(3d-demo의 것과 동일).
- 교육 내용은 `../3d-demo/data_v2.js`를 읽는다(중복 없음). 3D 학습 링크도 `../3d-demo/`를 가리킨다.

## 마이페이지 구성
- 프로필, 섹션 통과 수 / 확정 개념 수 / 미해결 오개념 수
- 섹션 4개 진행 카드: 이해도(80% 기준선), 상태(통과·진행 중·재도전 필요·잠김)
- 탭: 개념 보기 / 체크포인트 결과(개념별 막대 + 게이지) / 질문·답변(학습·체크포인트 필터) / 오개념(미해결·해결됨)

## 남은 일
- `RECORDS`, `QA`, `MIS`는 샘플 데이터. 백엔드(SQLite) API로 교체한다.
- 점수 계산은 화면 표시용. 실제 점수는 `backend/src/scoring.ts` 결과를 쓴다.
- Google 로그인은 버튼만 있음. CLAUDE.md의 확정 방식은 아이디+비밀번호(bcrypt)+JWT라 Google OAuth를 쓰려면 팀 확인 필요.

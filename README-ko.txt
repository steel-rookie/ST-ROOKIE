STEEL ACADEMY 교육 MVP

steel-academy.html을 Chrome 또는 Edge 최신 버전으로 열면 됩니다.
인터넷 연결이나 API 키 없이 3D 모델과 교육 데모를 볼 수 있습니다.

기능: 설비 선택, 3D 회전/확대, 공정 재생/속도 조절, 예시 튜터, 3문항 퀴즈, GLB 다운로드.
튜터는 실제 LLM이 아닌 준비된 답변 데모입니다.
3D는 실제 포스코 도면이 아닌 교육용 개념 모형입니다.
재료 애니메이션은 공정 흐름을 단순화한 것으로, 실제 압연·냉각·권취의 물리 시뮬레이션이 아닙니다.

수정 가능한 분리 소스는 source/ 폴더에 있습니다. source 폴더에서 python -m http.server 8000 실행 후 http://localhost:8000을 열 수 있습니다.
브라우저 화면의 실제 시각 검증은 수행하지 못했으며, JavaScript 구문·로컬 참조·GLB 구조를 검증했습니다.

# 팀원 테스트 안내: 제선 이해도 확인

제선 섹션 마지막의 '이해도 확인'을 실제 AI 튜터(Gemini)로 직접 풀어 보는 테스트입니다. 여러분의 답변은 AI 채점이 사람 판단과 얼마나 맞는지 확인하는 데 씁니다. 15분 정도 걸립니다.

## 답할 때 지켜 주세요

- **검색하지 말고 아는 만큼만 답해 주세요.** 틀린 답, 반쯤 맞는 답이 가장 도움이 됩니다.
- **되묻기도 자유롭게 해 보세요.** "그게 무슨 뜻이에요?", "힌트 주세요", "모르겠어요"도 그대로 보내면 됩니다.
- 맞춤법이나 말투는 신경 쓰지 않아도 됩니다. 평소 말하듯 쓰세요.
- 이름, 사번 같은 개인정보는 쓰지 마세요.
- 채점이 이상하다고 느끼면 개념 이름과 내 답변을 메모해 두었다가 함께 알려 주세요.

## 1. 준비 (처음 한 번)

1. [Node.js](https://nodejs.org) 22 이상을 설치합니다(24 권장).
2. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 Gemini API 키를 발급받습니다. 무료로 쓸 수 있고, 키는 다른 사람과 공유하지 마세요.
3. 저장소를 받고 테스트 브랜치로 바꾼 뒤 패키지를 설치합니다.

   ```bash
   git clone https://github.com/viiin2/ST-ROOKIE.git
   cd ST-ROOKIE
   git switch feature/checkpoint-ui
   npm ci
   ```

4. 프로젝트 폴더의 `.env.example`을 복사해 `.env`를 만들고, `GEMINI_API_KEY=` 뒤에 키를 붙여 넣습니다.

   ```
   GEMINI_API_KEY=발급받은_키
   GEMINI_MODEL=gemini-3.5-flash-lite
   ```

Windows PowerShell에서 `npm`이 막히면 `npm.cmd`로 바꿔 실행하세요.

## 2. 서버 실행

```bash
npm start
```

`제선 공정 알아보기: http://localhost:3000`이 보이면 브라우저에서 <http://localhost:3000>을 엽니다.

- 3000번 포트를 다른 프로그램이 쓰고 있으면 다른 포트로 띄웁니다. macOS·Linux는 `PORT=3001 npm start`, PowerShell은 `$env:PORT=3001; npm.cmd start`.
- 답변 기록은 `data/st-rookie.sqlite` 파일에 저장됩니다.

## 3. 이해도 확인 진입

1. 위쪽 공정 탭에서 **01 제선**을 고릅니다(처음 열면 제선입니다).
2. 아래쪽 설비 목록(소결 설비, 코크스 오븐, 열풍로, 고로) 오른쪽 끝의 **이해도 확인** 버튼을 누릅니다. 버튼 아래에 '시작'이라고 보이면 준비된 상태입니다.
3. 오른쪽 튜터 패널이 '이해도 확인 · 제선'으로 바뀌면 **준비됐어요**를 누릅니다.
4. 개념 3개를 차례로 묻습니다. 틀리거나 되물으면 튜터가 설명한 뒤 다른 각도로 한 번 더 묻습니다.
5. 끝나면 개념별 막대와 전체 이해도(기준 80%)가 나옵니다.
   - 80%에 못 미치면 **섹션 처음으로**를 누른 뒤, 다시 **이해도 확인**을 눌러 재도전해 보세요. 어려웠던 개념만 다시 묻습니다.

진행 중에 새로고침해도 이어서 할 수 있습니다. 제강·연주·열간압연은 아직 문제가 없어서 '준비 중' 또는 '잠김'으로 보입니다.

## 4. 끝나면

1. 터미널에서 `Ctrl+C`로 서버를 끕니다.
2. `data/st-rookie.sqlite` 파일의 이름을 `team-이니셜.sqlite`처럼 바꿔 테스트 담당자에게 보내 주세요. 질문, 답변, 채점 결과만 들어 있고 API 키는 들어 있지 않습니다.
3. 처음부터 다시 해 보고 싶으면, 파일을 보낸 **다음에** `data/st-rookie.sqlite`를 지우고 서버를 다시 켜면 됩니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 튜터 패널에 "튜터에 연결하지 못했습니다" | 무료 사용량 제한일 수 있습니다. 잠시 기다렸다가 같은 내용을 다시 보내세요. 계속되면 `.env`의 키를 확인하고 서버를 다시 켭니다. |
| "채점 오류"와 **다시 채점하기** 버튼 | 버튼을 누르면 방금 답변을 다시 채점합니다. |
| 다른 화면이 열림 | 3000번 포트를 다른 프로그램이 쓰고 있습니다. 2단계의 다른 포트 방법을 쓰세요. |
| 이해도 확인 버튼이 '연결 안 됨' | 서버가 꺼져 있거나 다른 포트로 떠 있습니다. 터미널을 확인하세요. |

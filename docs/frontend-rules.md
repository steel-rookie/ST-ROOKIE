# 화면(프론트) 작업 규칙

메인 화면을 새 버전(v3)으로 바꾸면서 AI 튜터 채팅과 이해도 확인 기능이 화면에서 끊긴 적이 있다(지금은 다시 연결되어 정상). 새 화면을 기존 화면을 복사해서 따로 만들었기 때문이다. 집을 새로 지으면서 전기·수도 배선을 안 옮긴 것과 같다. 겉모습은 멀쩡한데 불이 안 들어온다.

화면 작업을 할 때 아래를 지킨다.

## 1. 화면을 새로 복사해서 만들지 말고, 지금 화면을 고친다

디자인을 크게 바꾸고 싶으면 새 파일을 만들기 전에 단톡에 먼저 말한다. 같이 방법을 정한다.

## 2. AI 튜터 영역은 모양만 바꾼다

오른쪽 튜터 패널(채팅, [학습 | 이해도 확인] 탭, 공정별 "단련 완료" 표시)은 뒤에서 AI와 연결된 부분이다(`learning-chat.js`, `checkpoint-chat.js`). 색, 위치, 크기는 자유롭게 바꿔도 되지만 이 부분을 지우거나 새로 다시 만들지 않는다.

## 3. 바꾼 다음에 확인한다

- [ ] 로그인하면 메인 화면이 잘 열린다
- [ ] 튜터에게 질문하면 답이 온다
- [ ] [이해도 확인] 탭에서 시작 → 질문 → 결과까지 끝까지 된다

## 4. 메인 화면을 크게 바꾸면 리뷰를 요청한다

연결이 끊긴 데 없는지 빠르게 확인한다. 헷갈리는 것이 있으면 언제든 편하게 묻는다.
